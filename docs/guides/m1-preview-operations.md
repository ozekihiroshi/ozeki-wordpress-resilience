# 過去のM1プレビュー操作

2026年10月18日当時、2回目の模擬復元環境owr-m1-e3-2がlocalhost:18081を使用していた。現在の稼働状態は未確認。この記録を実サイトの隔離復元環境の案内と混同しない。

Ubuntuのプロジェクトルートで、操作前に `docker ps -a` と対象Compose設定・ポート使用状況を確認する。記録当時の停止コマンドは次のとおり。ボリューム削除はしない。

```bash
docker compose --env-file .local/e3-run-2/runtime.env -f .local/e3-run-2/compose.json stop
```

再開は同じ対象で `up -d`。既存プレビューとのポート競合を確認する。旧元環境を無条件に起動しない。実験資格情報を含むruntime.envは公開しない。実サイト候補の復元は公開ポートなしで試験後停止した別環境である。
