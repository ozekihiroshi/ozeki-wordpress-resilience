# 独立素材の最小抽出実装

[English](portable-content-extraction.md) | 日本語

[Reconstruct仕様](../spec/portable-reconstruct-minimum-jp.md)の抽出部分だけを実装します。静的サイト生成、既存の承認・バックアップ・復元、本番やAWSの設定は変更しません。

## 入口と成果物

`tools/portable-content-export.php`は、信頼しているWordPressをCLIで起動した後に使う読取り収集器です。最大200件のIDを明示し、パスワードのない公開済み標準投稿・固定ページ、必要なメタデータ、参照された添付原画像を取得します。ブロックは解析だけで、本文描画・ショートコードは実行しません。独自メタデータの値は出さず、未対応のキー名を一覧にします。

ただしWordPressの起動、URLやアップロード先を調べる関数には既存フック等が関与し得ます。侵害済みサイトのコードを安全に実行する仕組みではありません。今回動かすのは専用の生成環境です。

`tools/portable-content.py --source SOURCE.json --output NEW_DIRECTORY`は取得済みJSONをオフラインで処理します。外部URL取得や旧コード実行はありません。既存フォルダへの上書きを拒否し、途中失敗はincompleteとして残します。初期上限は入力64MiB、本文1件2MiB、画像1件8MiB・合計32MiBです。

| 出力 | 内容 |
|---|---|
| raw/source.json | 選択された元本文と記録。Web公開しない |
| content/*.json | 本文の文字・構造・画像／リンク参照 |
| readable/*.txt | WordPressなしで読める文章。Markdown／HTML描画はまだ行わない |
| media/・media-index.json | 実画像と元URL・名前・ハッシュ等の対応 |
| relations.json | 親子・本文リンク・アンカー・本文画像・アイキャッチの関係 |
| issues.json | ページ・位置別の欠落／未対応／要確認一覧 |
| manifest.json | 対象、件数、観測、ファイルハッシュ、処理状態。公開承認は常にfalse |

素材フォルダ全体を非公開で保管してください。原HTML・画像を保存できたことは、そのまま公開してよいことを意味しません。

## 何が出来て、何が残るか

基本本文を解析し、ページ親子、既知URLのリンクとアンカー、画像、アイキャッチを関連付けます。切れた参照・危険なURL方式・不足画像は未解決として残します。元URLの完全対応が基本で、別名URL・縮小画像URL・相対画像の発見等は不足を表示し、勝手に解決しません。メニュー、分類、テーマのヘッダー／フッターは未取得と明示します。

動的ブロック・表・ショートコードらしき記述・未知属性・独自メタデータ・壊れたHTMLは一覧にします。script等は正規化した文章から除きますが、原資料には保持します。未対応要素の文字が残っていても、正しく描画できると判定したものではありません。

画像は実体をハッシュ照合して保存します。収集時はパス逸脱とsymlinkを拒否します。PNG/JPEGの識別は先頭情報だけで、**画像デコード・再エンコード・無害化は未実装**です。画像ごとに要確認と記録します。別形式は制限付き原資料として.bin保存し、未対応を示します。欠落画像をネットワークから自動補充しません。

取得前後のDBレコード比較は原子的スナップショットや無侵害の証明ではありません。未確認状態を残します。一般利用向け導入画面・ホスト接続、幅広いメディア／メニュー／同期ブロック、強い取得整合性は後段です。

## 今回の専用試験

既存の通信隔離されたWordPress/MariaDB環境を再利用し、会社案内・サービス・連絡先の3ページ、実画像、欠落画像、非公開下書き、リンク切れ、未対応の表・動的ブロック・フォーム記述・ビルダーメタデータを作ります。作成後の収集前後でDBチェックサムを比較し、非公開情報の除外、実体・関係・欠落一覧、同じ入力の再処理の一致を確認します。本番書込みや復元試験ではありません。

次の未実装境界は、広い参照対応・必要ページの運用指定・画像処理方針等です。静的生成は今回の範囲外のままです。Backup for S3への必須依存も追加しません。

## 検証結果 — 2026年10月22日

単体試験10件と実WordPressでの確認10項目が成功しました。3ページ、コピー画像1件、関係6件、確認事項16件を保存しました。確認事項には意図的な欠落画像・非公開下書きの対象外・未対応要素を含みます。収集前後でDBチェックサムは変化していません。試験WordPressの削除後にも、素材ハッシュ・閲覧用文章・画像実体を確認しました。HTMLや静的サイトは生成していません。[検証記録](../../evidence-public/portable-content-extraction.json)。

初回は、試験データを作る段階でWordPressがscriptを除去したため、予定した除外検査が成立せず失敗しました。保存済み原資料で原因を確認し、試験用DBに限った直接保存と収集前の存在確認を追加しました。これは試験基盤の問題として記録し、初回結果は保持しています。最終試験の範囲では新たな環境障害・製品不具合は確認されませんでした。本番互換性を保証する結果ではありません。

補足：この資料は抽出処理の範囲です。後続の[静的プレビュー](portable-preview-jp.md)は実装済みで、別CLIとして提供しています。
