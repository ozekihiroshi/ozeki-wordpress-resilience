前回のローカル取得原本や復元ボリュームを再利用せず、S3固定Version IDから12オブジェクトを新しい領域へ取得した。取出しはdmの復旧ロールで短時間GETを署名し、手元WSLへ直接読み込む。保存元communityへの接続は不要だった。各固定版のサイズ・SHA-256・現在の保持モード/期限を照合し、保持短縮や期限切れも検出する。
