# 素材だけから作るローカル静的プレビュー

[English](portable-preview.md) | 日本語

`tools/portable-preview.py --package PACKAGE --output NEW_DIRECTORY [--image-runtime sha256:PIN]`で、前回の独立素材から確認用HTMLを生成します。WordPress起動・元DB接続・コンテンツURL取得・公開処理はありません。元素材を変更せず、新しい出力先だけを作ります。上書きと素材への重なり、未完了素材、パス逸脱・symlink・ハッシュ／容量不一致を拒否します。ハッシュ照合は素材内部の整合性であって、真正性・無侵害の証明ではありません。

出力は一覧index.html、ページ別HTML、ローカルCSS、検査を通った再生成PNG、build.jsonです。原HTML・SQL・旧PHP/JS・旧設定・秘密情報はコピーしません。各ページに未公開プレビューの表示、ページ間ナビゲーション、ページ固有／全体の確認事項を出します。一覧には選択したのに抽出されなかったIDも出します。

本文はescapeし、固定の許可タグだけを出力します。script・form・iframe等や外部リソースのURLを生成せず、CSPでも制限します。未解決リンクと外部リンクは動作させず確認事項にします。連絡先は文字として確認し、メールや電話の操作を自動生成しません。

新しい抽出ではHTMLのid位置を本文の順序付きノードとして元要素の直前に保存します。プレビューはリンクの節名を復号し、一意なローカルIDへ対応させます。重複した目印や位置情報のない旧素材はページへのリンクに下げ、「節の位置は未再現」と明示します。除外した実行要素をリンク先として復活させません。表やショートコードの残存テキストも参考表示であり、機能が再現された扱いにはしません。

画像は明示した固定PHP/GDイメージのCLIで検査・再生成します。別コンテナはネットワークなし・root読取り専用・非root実行・capability全除去・メモリ/PID制限付きで、WordPress・DB・元サイトのマウントは使いません。画像は8MiB、寸法4096以内、400万画素以内に制限し、PNG/JPEGをデコードして新しいPNGにします。元メタデータはコピーしません。これはリスク低減であり無害保証ではありません。未設定・検査失敗なら表示保留です。

前回の生成済み1x1 PNGにはIDATのCRC不一致があり、寸法は読めてもGDデコードが失敗しました。前回のハッシュ確認は元画像と同じバイト列を保存した確認でした。元素材はそのまま保持し、今回の画面では表示保留にします。別の正常な生成PNGで再生成の正常経路も確認しますが、元画像を勝手に修復・置換しません。

最初のブラウザ検査では、ローカルfile URLのCSS内部ルール参照がSecurityErrorになりました。試験側を実際の適用スタイルの確認へ修正し、初回ログと画面は保持します。試験方法の問題であり、原因不明の本番環境障害には分類しません。

静的プレビューの生成は公開承認ではありません。会社情報や連絡先の正しさ、欠落機能・未対応部分は担当者確認が残ります。一般サイト向け導入UI、承認条件変更、S3接続、自動公開は追加していません。

## 検証結果 — 2026年10月22日

単体試験7件、Chromium確認6項目が成功しました。保存済み3ページの表示・内部リンク・不足一覧・390px幅で横にはみ出さないことを確認しました。ブラウザはnetwork none・ポート公開なしで、元WordPressのコンテナは存在しません。素材の全ハッシュは変更されていません。抽出時の16件に今回の表示制限5件を加え、確認事項21件を表示します。元の試験画像は表示保留とし、別の正常PNGで再生成を確認しました。公開準備完了の判定ではありません。[検証記録](../../evidence-public/portable-preview.json)。

2回目のブラウザ試験でも、共有WebDriverヘルパーがerrorキーを持つ戻り値をエラー応答とみなして停止しました。検査値を文字列で返すよう試験基盤だけを修正し、3回目に成功しました。先のログ・画面は保持し、製品側の判定は緩めていません。

## 正常画像での一貫検証

新しい企業案内サイトの生成データに、GDで作った正常な480×240のPNGを使います。抽出→元コンテナの終了→素材だけからのプレビュー生成を通します。前回の壊れた画像の素材・記録は変更しません。新しい画面は3ページ・再生成画像1件・確認事項18件で、欠落画像／ページ、未対応フォーム／ブロック、メタデータ等の問題を引き続き表示します。節への移動先は元の見出し位置を保持します。確認範囲は対応済みの部分であり、任意のテーマやレイアウトの完全再現・無侵害の証明ではありません。[一貫検証記録](../../evidence-public/portable-roundtrip.json)。
