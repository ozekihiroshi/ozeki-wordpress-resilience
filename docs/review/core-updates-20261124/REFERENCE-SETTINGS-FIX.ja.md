# 参照設定2項目の保存・復旧修正（2026-11-24）

## 変更内容

`default_category` と `wp_page_for_privacy_policy` を日常保存の共通設定契約に追加した。初回保存・変更検知・記録・適用が同じ一覧を使用する。参照IDは0以上の整数表現に限定し、0を明示的な指定解除として扱う。

履歴の途中ではなく、復旧点全体を構成した後で参照先を確認する。カテゴリーは定義とcategory分類の両方、プライバシーポリシーはpage型の存在を確認する。見つからない参照は適用時に0へ解除し、既存の未適用事項へ記録する。無関係な対象への付け替え、原本の書換え、対象を生成する穴埋めは行わない。指定解除後は管理者が必要な対象を選び直す。

WordPress標準では指定中のデフォルトカテゴリーの削除は拒否される。削除したい場合は先に別カテゴリーへ変更する。プライバシーポリシーページの完全削除はWordPressが指定を0へ変更する。その完了状態を記録する。デフォルトカテゴリーの0指定はAPIレベルの解除試験であり、管理画面に解除操作があるという意味ではない。

## 互換性

形式を `core-updates-5` 系へ更新した。公開前候補間の保存データ互換性は保証せず、保存元・復旧先を同じ版に揃えて健全な保存元で新しい初回保存を作成する。既存原本・履歴は変更しない。core-updates-4の実読取り処理が新しい原本・初回保存・独立索引を拒否することを確認した。
