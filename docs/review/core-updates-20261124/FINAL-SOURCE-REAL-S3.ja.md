# 最終ソースとMarkdown Documents 0.1.3の実S3往復確認

2026-11-24。main取り込み前の開発ソースと、WordPress.orgから取得したMarkdown Documents 0.1.3を使用した。代表ケースの合格条件22項目がすべて一致した。製品コードの修正は行っていない。

## 環境と対象

- dmの専用Docker内部ネットワーク。外部公開ポートなし。保存元・初回復旧先・再復旧先を新規に用意。
- WordPress 7.1.4 / PHP 8.3、WP-Members 3.5.8.3、TablePressとMarkdown Documentsを通常インストール・有効化してから復旧。
- S3は既存の試験専用バケットの新規ランダムprefix。PHP SDKの操作を、既存EC2ロールを使う試験中継で実S3へ送信した。認証情報をコンテナへコピーせず、キー範囲を制限し、暗号化・新規作成のみを許可。上書き・削除は禁止。
- 合成記事・文書・画像・会員・表・メニュー・カテゴリーのみ。本番サイトの内容は使っていない。
- 最終ソースのアーカイブSHA256: `1ea7f38c4e04d12f8279e2bdadea762026a5da7f2e4b0603f68b9e0ee83e3a04`。
- 公開配布Markdown ZIPのSHA256: `039f5c110c5125d3751fb11de8376f358b0df5d61d25cc15a932c4f004d35c21`。これはWordPress.orgが再圧縮したZIPで、前段の公開確認では候補と全517ファイルの内容が一致した。

## 結果

| 確認 | 結果 |
|---|---|
| 初回保存とその後の正式履歴からの復旧 | 成功。キャッチフレーズ、クラシックメニュー、デフォルトカテゴリー、プライバシーポリシーの参照先が一致 |
| 履歴書込み失敗と再開 | 未確定4件を保持し、再開後は0件。後の状態も一致 |
| 必要プラグインが無効な復旧先 | 必要版・有効化・再確認の案内を表示。復旧先の記事を変更せず停止。有効化後は成功 |
| Markdownの直接表示・埋込み | 匿名HTTPで本文非表示。会員権限では本文表示。冷・温キャッシュ、パスワードなし・ありの判定も維持 |
| 復旧後の編集・再保存・再復旧 | 通常編集のnonceを使った文書追記、メニュー変更、参照先の再指定、表の追加行が別の復旧先に戻った |
| 文字と構造化データ | ショートコード文字列は復旧後も実行されず、表セルの `<24>` 等の値は変化しなかった |
| ページ制限とファイル制限 | ページだけを会員限定にした画像は公開ファイルのまま。ファイル自体に条件を付けた画像は公開領域に配置せず、原本を保持。再保存・再復旧後も維持 |
| 準備済み設定 | 独自テーマ設定を維持。別物の添付とIDが衝突する準備済みロゴは、誤った画像を表示しないよう解除 |
| ソフトウェアと原本 | 全3環境のプラグインファイルが不変。最初に保存した85オブジェクト版は、再保存後の152版の中でもVersionId・ETag・サイズ・最新状態が一致 |

最初のHTTP記録はリダイレクトの先頭応答のみを要約していたため、今回の試験prefixを読取り専用で新しい隔離先へ再復旧し、画像URLだけ追加照合した。公開画像はHTTP 200/image/pngで原本68バイトとハッシュ一致。非公開画像URLは301の後に200/text/htmlとなり、画像本体は配信されなかった。403/404を返したという意味ではない。この追加確認でも全S3オブジェクト版は不変だった。
