# 先頭固定・メニュー・パーマリンクの日常保存修正

2026-11-24。公開前の開発ブランチでの修正。製品公開・本番反映は行わない。

## 原因と変更

初回保存には含まれる情報が日常の変更検知に含まれず、復旧処理が成功しても古い状態へ戻っていた。

- 先頭固定表示とパーマリンク設定を、日常保存する基本設定の共通定義に追加。初回保存もこの定義を参照する。先頭固定は文字列にせずID配列として検証・適用する。空配列による解除も保存する。
- メニューの項目・項目メタデータ・定義・所属・順序を一組で保存。通常の項目保存・メタデータ変更・分類変更・削除完了を検知し、既存の永続キューと正式履歴を使う。
- 復旧ではメニューに属する状態だけを置き換え、削除も反映する。他の記事とのID衝突は拒否する。HTMLやURL等の適用時の安全確認は既存のRecoveryRulesを通す。
- テーマの選択、プラグインのインストールや初期化、復旧先の運用設定の再生成は追加しない。

これは今回実証した3件の修正である。初回保存に含まれる全設定を無条件に日常復旧の対象に拡張したものではない。残る設定は、保存元から戻すものと復旧先で維持するものを区分して判断する。

## 互換性

更新契約を `owr-core-updates-3` に更新。対応する原本・初回保存・独立索引の識別子も3にする。メニュー状態と配列型の先頭固定条件を理解しない読取り処理による誤適用を防ぐためである。

公開前候補間の保存データ互換性は保証しない。保存元・復旧先を同じ対応版に揃え、健全な保存元で新しい初回保存を作る。既存の原本・履歴は移行・上書き・削除しない。旧形式を新形式に読み替える穴埋めも行わない。独立原文の読取りと、復旧点全体の適用互換性は別に扱う。

## 再発の検出

`tests/navigation-state.php` を修正前に実行し、設定契約の不一致で失敗することを確認した。修正後は以下を照合する。

- 配列と文字列の設定値が同じ意味で適用される。
- メニュー変更・削除が項目と関係情報にまとめて反映される。
- 記事IDへの衝突、不正な先頭固定ID、以前の公開前更新契約を拒否する。
- メニューをすべて消しても記事は残る。

このテストを既存のcontracts workflowに追加した。ローカル実行の成功とGitHub Actionsの実行済みとは区別する。今回はpushしていないためActionsは未実行。

## 隔離確認

dm上の使い捨てDocker、合成データ、ファイル保存に差し替えたS3 SDKを使用。実S3・本番へのアクセスは行わない。標準WordPress API、WP_Query、wp_nav_menu、get_permalinkで復旧後の状態と表示を照合する。

- 先頭固定の解除、別記事への固定、記事更新、復旧先での再変更・再保存・再復旧。
- メニューの名前・URL・順序変更、追加・削除、記事更新、復旧先での再変更・再保存・再復旧。
- URL形式変更、記事更新、復旧先で別の形式へ再変更・再保存・再復旧。
- 新しい初回保存からの復旧を対照として照合。

上記3件はすべて日常保存からの復旧・再保存・再復旧が一致した。追加確認したメニュー全体の削除も反映され、記事本文は維持された。開始時の試験オブジェクトは全件ハッシュ一致。試験コンテナは削除済み。

証拠は非公開の試験領域 `release-readiness/navigation-fix-20261124` に保存した。要約は `navigation-verification.json`、今回の変更ファイルのハッシュは `navigation-source-hashes.json`。再現用の合成データだけを `tools/testing/core-update-scenarios/navigation` に置く。

既存のコメント・投稿者、予約公開、保全識別情報、添付削除の回帰テスト、および原本・初回保存・独立索引の形式確認も成功。旧rc.21読取り処理と直前のcore-updates-2読取り処理による新形式の拒否を確認した。保全識別情報・添付削除テストは初回の呼出し引数が不足したため失敗し、必要なパッケージパスを付けた再実行で成功した。

最終メニュー試験は最終ソースで実行した。先頭固定・パーマリンク試験後に追加した保存時の設定検証は、同じ値検証を保存前にも呼ぶ防御であり、単体テストと形式・適用規則の回帰確認を行った。HTTP到達性等の未実施事項をこの成功に含めない。

ブラウザ操作、HTTPでのURL到達性・リダイレクト、ブロックナビゲーション、実S3、Plugin Check、新ZIPは今回の確認範囲外。本番・既存の原本と履歴・既存ZIP・タグは変更しない。
