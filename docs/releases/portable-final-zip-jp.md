# 素材抽出・静的プレビューの最終ZIP検証

試作版 0.1.0-dev.1です。[英語版とZIPハッシュ](portable-final-zip.md)、[検証結果JSON](../../evidence-public/portable-final-zip.json)を参照してください。本番変更・自動公開・正式リリースは行っていません。

プラグインZIPは前回候補と同一バイト列です。実WordPressのPlugin_Upgraderによる新規導入・有効化・同版上書き更新を確認し、設定・Cron・wp-config・要求記録・外部報告を保持しました。スキーマ移行の確認ではありません。

新機能は開発キットのCLIに含まれます。展開したZIPの全ファイルをmanifestと照合し、そのコードで単体21件と生成サイトの抽出試験を実行しました。元コンテナ終了後に3ページ・正常画像1件を生成し、ブラウザ8項目で画像表示・節の位置・不足表示・モバイル表示を確認しました。以前の素材も変更せず利用できます。

素材はコードと別の場所に保管し、キット更新は新しいディレクトリへの展開で行います。会社情報の正しさや未対応機能は人の確認が必要です。任意のテーマの完全再現、無侵害、自動公開を保証するものではありません。

最初のZIP候補も保持しています。最終v2は試験前に日本語READMEの古い表記を訂正したものです。この結果資料はZIP凍結後に作成したため、そのZIP内には含まれません。累積した試作機能すべてを再認証した試験ではありません。
