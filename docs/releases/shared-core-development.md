# 初版公開と共通DB部品導入の結果

2026年10月18日。計画1〜5を、最初の抽出対象であるPHP DBダンパーについて実装・検証した。

| 作業 | 結果 |
| --- | --- |
| 1 初版公開 | GitHub公開リポジトリ、M1タグv0.1.0-alpha.3、GPL-2.0-or-later、例示設定と公開用集計を用意 |
| 2 契約定義 | 06-backup-core-contract.mdに入出力、失敗、一時ファイル所有権、製品責任を定義 |
| 3 共通化 | PHP DBダンプと補助処理11ファイルをBackup Core 0.1.0へ抽出。保守元はpackages/backup-core |
| 4 Resilience再実証 | WordPressを読み込まない収集、実S3固定版取得、元の模擬環境停止、新規ボリューム復元で16＋14項目合格 |
| 5 既存製品へ導入 | 生成した固定版をlibsへ同梱。旧APIの互換エイリアス、native/PHPの回帰試験とZIP復元に合格 |

公開前後の再現性検査で、初期タグの試験が非公開の基準データと.local内の依存物を参照していた問題を発見した。実測原本を公開するのでなく、独立した合成fixtureとComposerの依存導入へ修正した。alphaとalpha.2の履歴は変更せず、クリーンなクローンで63検査に合格したalpha.3を推奨する。

共通部品の契約試験10件、既存API互換7件、同梱ハッシュの一致を確認した。既存製品のnative/PHPはそれぞれ1,007行のDB復元、強制終了6箇所からの再開を含むPipeline94項目、ZIPからのWordPress復元46項目に合格した。AWS SDKの名前衝突検査もビルド時に合格した。

検証用ZIPのSHA-256は0b4f314a17b26b865d03b91db5a37536e1e58ae318a256536503c1a2eed7d57d。既存の0.3.0公開候補を上書きせず、別の一時出力先で構築した。WordPress.orgへの公開は行っていない。既存製品の未追跡の文書フォルダ・公開準備スクリプトも変更していない。

今回のS3試験は、新しいDBだけを保存・固定版取得し、以前S3から取得済みの他資産と組み合わせた派生試験である。新しいサイト全体セットをS3に再発行したとの主張はしない。IAM分離・真正性・ホストOS独立性は依然未達/未検証である。

S3転送・圧縮・メディア全体の共通化、完成版の単独導入UI、他方のプラグイン検出・移行案内は残る。DBダンプの最初の共通化を完了したことと、製品全体の完成を区別する。
