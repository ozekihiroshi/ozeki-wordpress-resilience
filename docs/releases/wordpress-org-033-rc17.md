## 修正と復旧方針

復旧先のWordPress・テーマ・プラグインは管理者が信頼できる配布元から導入し、通常のセットアップを済ませます。Resilienceは第三者プラグインのインストール・初期化を行いません。

WP-Membersの部分的な保存情報で復旧先設定を置き換え、初期値を再生成していた原因を修正しました。includes/install.phpの読込みと初期化呼出しを削除し、準備済みの動作設定・版情報を維持した上で、対応する会員情報・項目定義・閲覧条件を戻します。不足条件は置換前に表示します。保存元のURLだけを変換し、準備済み設定の文字列は変更しません。

未配布だったPDF等の添付一式の修正も含みます。原本・生成プレビュー・添付情報・閲覧条件を初回保存と日常保存で共通に照合し、登録後の記事の再編集を待たずに正式履歴へつなぎます。原本不足は未完了として扱います。
