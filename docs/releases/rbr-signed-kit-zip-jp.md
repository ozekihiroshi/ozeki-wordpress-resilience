# 署名付き再構築キットのZIP候補

試作`0.1.0-dev.1`です。本番変更・自動公開はしません。主文書は[英語版](rbr-signed-kit-zip.md)です。

新しい候補ディレクトリへビルドし、ZIPと展開全ファイルをマニフェストと照合します。既存の専用試験を再利用し、WordPressの実際のPlugin_Upgraderで新規導入とportable-final-v2からの同番号上書き更新を行います。設定、cron、wp-config、要求記録、外部報告・履歴が無効化／再有効化を含めて保持されるか確認します。

開発キットは新しい配置先へ展開し、展開したコード自身の署名・固定版・計画・比較・配布試験を実行します。コード外に置いた試験用受領票・承認・公開信頼情報・設定・取得記録・再構築履歴をハッシュ比較し、旧コードも変更しません。CLIのヘルプと署名なし入口の拒否も確認します。秘密鍵・認証情報・取得した実行イメージ・復旧素材はZIPへ入れません。

検証範囲は配布と導入・更新・保持です。S3再送、OS再起動、再構築試験やスキーマ移行を繰り返すものではありません。実S3・署名・再構築の証拠は前回結果を別範囲として参照します。同一ホスト内の権限分離、Docker互換性などの制限は残ります。最終ZIPのハッシュと結果は凍結後にevidence-public/rbr-signed-kit-zip.jsonへ記録し、検証済みZIPを後から変更しません。

前提としてPHP試験前に同梱composer.lockどおりの依存物を導入します。vendorはZIPへ同梱しません。最初の候補はこの手順不足でWordPress導入前に停止しました。final-v2では前提を明記し、既存のローカルComposerキャッシュから通信せず導入します。生成されるvendorとZIPのソースファイルの一致検査は分けます。
