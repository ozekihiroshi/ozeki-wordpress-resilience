# Multi-material console 0.2.0 ZIP validation

The plugin and matching operator kit in this validation are identified by the hashes in [the evidence](../../evidence-public/site-materials-console-zip-validation.json). Earlier 0.2.0 archives are preserved and are not interchangeable by filename alone.

The frozen kit passed 38 related tests. Fresh installation and update from the previous size-fixed 0.2.0 plugin each passed 45 real-browser checks using Plugin_Upgrader. Settings, pending requests, reports, legacy history fixture, Cron, posts and metadata were preserved. Reinstallation after reconstruction retained the new generation report and requests. Both cases reconstructed seven-material and four-material generations and matched their Q. The external kit also read an old generation, preserved existing files and extended its history.

These ZIP lifecycle trials use a persistent S3 double, not new cloud writes. The prior unassisted real-S3 trial remains separate evidence. No production change or automatic publication occurred. No new environment or test-harness failure occurred. Matching plugin and external kit updates are required. Dedicated targets are temporary private drafts; preview, retry, cleanup UI and durable deployment are not included.

Validation records were added after freezing; the ZIP bytes were not changed afterward.
