# 0.1.0-dev.1 初版候補（試作版）

これは完成版の公開ではありません。WordPress用ZIPと外部処理用開発キットを分けています。ZIPは2026-10-21の検証済み内容をそのまま保持し、manifest.jsonで識別します。古い同番号候補とはハッシュが異なります。

プラグインZIPの新規導入・既存候補からの置換・無効化と再有効化・設定と履歴保持は専用環境で確認済みです。詳細は ../../evidence-public/status-report-zip.json と ../../docs/guides/status-report-zip.md を参照してください。

開発キットは試験時点の固定スナップショットです。以後のPRレビュー文書・CI設定・最終試験集計はリポジトリ側に追記されており、現在のツリー全体をこのキットと同一とは扱いません。プラグインの収録8ファイルは現在のソースと一致します。ZIPアップロード画面操作、汎用サイトへの導入、本番外部サービスの更新を一括保証するものではありません。

72時間観測は別判定です。3日次枠の完了は連続観測の完了を意味しません。最短到達は2026-10-22 15:55:56 JST。既存の2つの観測空白を保持し、最終合否は未判定です。

WordPressへ入れるのは ozeki-wordpress-resilience のZIPのみです。外部処理・IAM・独立署名・監視の準備なしにサイト保護は始まりません。感染していないことの保証やマルウェア除去機能はありません。署名は承認した固定版と内容の対応を検証するもので、安全な内容であることを自動認定しません。
