# Experimental portable-content candidate

These are the unchanged, verified `0.1.0-dev.1` final-v2 bytes, not a formal release or publication authorization. Use manifest.json for exact file hashes. The development kit contains CLI extraction and local preview tools; the WordPress plugin ZIP does not add those admin actions.

See [English acceptance](../../docs/releases/portable-final-zip.md), [日本語](../../docs/releases/portable-final-zip-jp.md), and the English/Japanese repository README for supported content and omissions. Acceptance summaries and final PR review documents were written after freeze and are not included in these bytes. The kit also contains earlier cumulative same-host recovery work; it is not evidence that general incident reconstruction is complete.
