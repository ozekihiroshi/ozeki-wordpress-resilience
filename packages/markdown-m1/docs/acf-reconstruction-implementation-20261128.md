# ACFの通常登録による再構築：開発用実装

2026-11-28。前段の方式確認を実装へ移した記録。製品UIへの切替、mainへの取り込み、公開は未実施。

## 変更内容

- `src/AcfReconstruction.php`：初回素材と選択した正式履歴から得た状態を読み、公開済み／非公開の正式な投稿・固定ページに属する定義・値・参照を登録計画にする。元の素材には書き込まない。
- `SiteSnapshot::acfRegistrationPlan()`：既存の素材読取り・履歴再生の入口を利用する。保存形式・保存処理は変更しない。
- `tools/reconstruct-acf.py`：ACF管理画面の既存JSON取込みと投稿編集フォームを使用する隔離環境専用ツール。nonceは実際の画面から取得する。定義は通常JSONエクスポート、値は編集画面を読み返して確認する。

事前に同じ版のACF無料版を準備する。保存定義の可搬化はACF自身の通常エクスポート準備処理を使用する。第三者プラグインの変更・導入・初期化、直接DB配置、保存後のメタデータ補正、キャッシュ修復は行わない。定義のキーは論理参照として保ち、DB IDは新しく割り当てる。

値は保存素材から取り出してそのままフォーム引数に渡す。独自のエスケープ追加・型の修復・配列の並べ替えを行わない。HTML上の複数選択は定義順に並ぶため、画面の読み返しでは選択内容を比較する。保存値そのものの順序・内容は隔離試験の別の読取り比較で確認する。

## 保留・停止の扱い

- 未対応型、対応できない配置条件、定義不足、値の欠落・多重保存があれば計画に理由を残し、この開発用実行単位の書込みを保留する。一部だけを黙って登録しない。
- 既存のグループキー・フィールドキー・項目名との衝突は取込み前に停止し、上書きしない。
- 対象投稿は新しいIDを明示的に対応付け、下書き／非公開で準備する。ツールは自動公開しない。通常保存時も本文・タイトル・公開状態等の維持を照合する。
- 通常取込み／保存後の結果が一致しなければ停止し、実行記録を残す。取込み後に失敗した場合は部分的に登録されている可能性があり、無条件の再実行や内部補正はしない。
- 同じ版の通常JSON取込みに対応するDB定義・基本型を対象にする。PRO・参照型・入れ子等へ対応範囲を広げていない。

## 確認

`acf-reconstruction-implementation-20261128-results.json` と `../tests/acf-reconstruction-implementation/` が根拠。

dm上の外部接続なし・ポート非公開の使い捨てDockerで、WordPress 7.1.5 / ACF無料版6.8.10 / PHP 8.3を使用。S3を使用せず合成データだけで確認した。

- 基本15種類・16項目を、実装した登録計画とHTTP実行ツールで再構築。
- 初回素材に通常編集後の合成正式履歴1件を既存 `AcfHistory::replay()` で適用し、追記後の値を使用。
- 定義・保存値・参照関係を比較。投稿・グループ・フィールドのDB IDは新しくした。
- 下書きのまま登録を完了してから、試験手順で公開し通常テーマで表示。
- 日本語、バックスラッシュ、`a:0:{}` 等の文字列、数値0、日付、選択値を確認。
- 無編集の再保存、文字列変更、checkbox変更、複数select解除後の表示と再保存を確認。
- 復旧先の無関係な準備済みグループを維持。
- 未対応型・欠落値は書込み前に保留、既存定義との衝突は上書きせず拒否。
- ACF本体と初回素材のハッシュ不変、試験環境削除エラーなし。

最初の照合では、複数選択のHTML表示順と保存配列順を同じものとして比較して停止した。入力・保存値を変更するのではなく画面照合を修正した。また、準備済みグループを追加した試験では、再登録したグループとの比較と準備済みグループの維持確認を分離した。いずれも登録後のデータ補正はしていない。

## 利用入口

記録した版のACFが有効な環境で `SiteSnapshot::acfRegistrationPlan()` から計画を取得し、新しい投稿ID対応を用意する。

```text
python3 tools/reconstruct-acf.py --isolated --url <隔離サイトURL> --username <管理者> --plan <計画JSON> --post-map <新ID対応JSON> --journal <未使用の実行記録パス>
```

管理者パスワードは対話入力。実行記録が既存の場合は上書きしない。この入口は本番向けUIではなく、隔離環境での開発判断用。
