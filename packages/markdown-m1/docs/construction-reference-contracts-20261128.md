# 画像URL・CF7ハッシュの保存時参照契約

2026-11-28。開発用・隔離環境での確認。公開候補の認定ではない。

## 今回の変更

画像を通常のWordPress RESTアップロードで登録するとき、入力ファイルのバイト列・送信ヘッダーと、成功時の添付ID・原寸URL・生成サイズ別URLを記録する。投稿・Markdownの操作時には、そのURLがどの添付ID／サイズを参照しているかと、入力中のバイト位置・元の文字列を記録する。

CF7は通常登録後、公開メソッドで生成済みハッシュを読み取り記録する。埋込みを保存するときは `wpcf7_get_contact_form_by_hash()` で対象フォームを特定し、フォームIDとの関係を記録する。CF7と同様、数字のみのハッシュも、旧来の数値IDより先にハッシュとして解決する。

追随側は構文・ファイル名・スラッグ・似たURLから参照を探さない。通常登録が返した新しい添付IDとURL、および登録したIDを指定して通常のCF7 REST一覧から取得したハッシュを対応付け、記録済みの位置だけを置き換える。縮小画像URLをファイル名から組み立てる処理はない。画像タグの `wp-image-ID` も、保存時にURLとの一致を確認して別の型付き参照として記録する。通常のtitle文字列には同じ数字があっても手を加えない。

Markdown入力原本のバイト列は変更しない。通常取込みへ渡す新しい入力にだけ、記録済み参照を適用する。入力時のファイル名は維持し、同名ファイルの扱いはWordPressの通常アップロードに任せる。

開発用の記録・契約・初回保存アンカーをv4へ分離した。v3以前の不足情報を推測して補わず、既存の記録は書き換えない。本番のS3原本・正式履歴の形式を移行したものではない。

## 確認結果

S3なし、専用の内部Dockerネットワーク、合成データのみ。初回保存から取得した投稿者素材を通常登録した結果と、自動記録だけを追随側へ渡した。試験側の構築手順や旧ID→新ID表を追随入力には使っていない。

- 画像アップロードからページ・会員設定・文書・表・フォーム・ACF・会員・受信までの **20操作** を、記録順のまま追随した。
- 復旧先に同名の画像を先に置き、WordPressが別名を割り当てても原寸・縮小画像の内容が一致した。準備済み画像も維持された。
- Markdownの取込み・編集後の原文、ページ内の画像URL・ルート相対URL・添付IDクラス、CF7ハッシュ形式の埋込みを確認した。
- 新しい画像URLから取得したバイト列と、通常のページHTMLに新しいCF7フォームが表示されることを確認した。追随先からCF7への再送信は0回。
- 会員ページ参照・会員項目・閲覧制限・ACF定義と文字列値・表の値・Flamingo受信内容を引き続き確認し、通常のページ再保存でも参照を維持した。
- 高速な契約試験では、似た名前の外部ドメインを変更しないこと、似たパス・クエリ付き未解決URL・不明ハッシュ・不足する復旧先画像サイズを推測で埋めないことを確認した。

最終実操作・比較部分 **35.985秒**、環境再利用を含む試験全体 **42.682秒**。専用DBの合成初期状態への戻しは0.355秒。初回のDocker準備は42.447秒だった。これは開発試験の所要時間であり、本番規模の性能見積りではない。

高速確認は既存601件＋プラグイン契約17件＋今回の参照契約14件＋フォーム参加項目4件のアサーションであり、独立した実サイトケース数を示してはいない。

証跡: [最終結果](construction-reference-contracts-20261128-results.json)。

終了時に、6プラグインの配布ZIP内2,703ファイルと保存元・追随先の実ファイルのハッシュ一致を確認した。専用ラベルを検証したコンテナ・ボリューム・ネットワークのみ削除し、終了処理エラーは0件だった。

## 境界と未確認範囲

今回の画像実試験はPNGの通常REST生バイトアップロード、原寸・thumbnail、引用符付きHTML img、単純なMarkdownインライン画像が対象。JPEG等の契約は通常APIへ渡すが、今回の画像形式別実試験はしていない。複雑なブロック属性、srcsetの再構成、ページ相対の `diagram.png`、コード領域を含むMarkdown画像、画像編集・置換・削除の全パターンは保証していない。元のサイト内で特定できない参照は保留する。

外部画像はURLの文字列を維持するだけで、外部ファイルを取得・保全する機能ではない。原寸と異なるサイズを復旧先が生成できなければ、他サイズで代用せず停止する。

この試験は初回保存の投稿者素材とその後の自動操作記録の接続を使う限定試験で、既存の全初回保存・正式履歴・実S3との統合を再認定したものではない。UI全操作、全画像構文、復旧全体の中断再開は別の範囲。ブラウザJavaScript操作や本番導入は行っていない。

本番・既存原本・履歴・ZIP・タグ、研究側の既存変更は保全。申請・メール返信は保留。新しい公開ZIP、マージ、pushは行っていない。
