# GitHub Pre-release v0.3.1-pre.2 — 配布準備済み・未公開

[English](prerelease-2.md)

WordPress保守技術者向けの試験版で、安定版・WordPress.org申請ではありません。予定タグは `v0.3.1-pre.2`、製品ZIPは `ozeki-wordpress-resilience-0.3.1-pre.2.zip`、表示版は0.3.1です。ファイル名と付属SHA-256で識別します。今回タグ・リリースは作成しません。

## 今回含む機能

公開済みpre.1に対し、初期スナップショット／完全Checkpointの全資源を固定版から再取得・照合してからマニフェストを確定する処理、週次・月次・年次GFS設定、更新なしでも独立一式を取得する処理、保持規則に従う手動・定期削除、Object Lockの正当な設定なし判定を含みます。READMEの対応コンテンツ・アダプターと原本／付随情報の分離を維持します。

Baselineは管理者が信頼を判断した最初の独立復旧点です。通常Checkpointは保全済みS3資産と正式履歴だけから作り、未記録のWordPress変更を混入しません。現在状態の再取得は新しいBaselineという別操作です。保持したCheckpointと必要な後続履歴から、元環境なしに再構築します。

## 証拠と利用条件

実行コード・依存ライブラリは検証済みgfs-lock-read候補と全件同一で、文書だけを更新しました。候補の新規導入・更新では設定・未確定試験データ・履歴・復旧結果を保持しています。その証拠を再利用し、今回のZIP自体を再導入したという主張はしません。

実S3では保存・再取得、保持Checkpoint＋後続履歴からの復旧、管理画面での旧17版削除、定期処理での旧14版削除と有効な週次基点の保持、残存定期基点からdmへの復旧を確認しました。最初のPUTを拒否する試験用注入では、マニフェスト確定・削除なし、28版不変、失敗表示・次回予約を確認しました。実AWS障害ではありません。

バージョニング、対象範囲を限定した読書き・全版一覧・ロック確認権限が必要です。削除する範囲だけに固定版削除権限を付与します。S3削除保護は任意ですが、既存バケット／固定版のロックは適用され、回避しません。最新点、有効なGFS区分、期間境界の基点と必要な履歴・資源を保持します。手動削除は規則上期限切れの候補だけで、保持中の任意点の強制削除・全初期化ではありません。

## 約束しないこと

完全な無害化、全プラグイン互換、無条件の復旧成功は保証しません。対応範囲の再構築には互換性のあるWordPressと権限の準備が必要です。未知の取得済み情報は保持しますが無条件には適用せず、未確定操作は復旧対象外です。

定期試験は実時刻到来後のサーバからの標準wp-cron.php実行であり、HTTPループバックではありません。長期反復、自然な月次／年次期限経過、実S3の保護中の削除・削除途中停止は未検証です。WP-Cronは厳密な時刻保証ではなく、失敗時は停止して原因を確認します。復旧の自動継続・DNS切替・メール再送は保証しません。
