# ACF無料版の基本フィールド — 公開ラインへの統合候補

公開済み、または既に保護対象となった投稿・固定ページで、完了したACF保存を取得します。値・フィールド定義一式・フィールドキー参照を別々のJSON原本に分離し、未知の設定と生のメタ情報も原本に残します。正式履歴の確定には既存の固定版再取得・ハッシュ照合と未確定キューを利用します。WordPressのフィールド保存だけではS3確定にはなりません。キュー登録後の失敗は未確定として残り、管理者が履歴を再開します（登録前の失敗は末尾に記載）。本文の履歴とACFフィールドの履歴は別々の確定操作です。

自動適用は、DBで定義したグループの投稿・固定ページを指定するpost_type配置規則と、text、textarea、number、range、email、url、select、checkbox、radio、button_group、true_false、date_picker、date_time_picker、time_picker、color_pickerに限定します。サイト全体復旧で認定した値・選択肢・フィールドキーを再構築し、未対応の型・設定は原本に保持して未適用理由を表示します。復旧先には記録したものと同じバージョンのACF無料版の有効化が必要です。Baselineと後続履歴に同じ規則を適用し、CheckpointはS3資産・正式履歴だけから作ります。

ACFの対応は無料版だけに限定し、PROは対応予定に含めません。画像・投稿・ユーザー・分類を参照する型、入れ子の型、カスタム投稿タイプ、Options・ユーザー・ターム・コメントのフィールド、PHP・Local JSONによる定義、保護対象記事のフィールド保存を伴わない定義単独の編集は、今回の受入範囲外です。定義単独の変更には新しい信頼済みBaselineを使用します。復旧は記録したACF版と上記の対応型を対象に行います。他の型には、それぞれに対応した復旧規則が必要です。公開済みZIPにはこの対応は含まれません。
